# Exemple de calibrage (ce n'est pas ton projet)

> **Un exemple, pas une solution.** Ces deux pages montrent le niveau de précision attendu pour le cadrage (PF.1) et le protocole (PF.4), sur un dataset qui n'est pas un fil rouge du workbook : la demande horaire de vélos en libre-service de Washington (Bike Sharing, UCI). Ton projet porte sur **ton** dataset, avec **tes** choix ; ne recopie ni la structure des phrases ni les seuils. Lis-les après avoir écrit ta première version, pour comparer.

| Fichier | Étape | Ce qu'il montre |
|---|---|---|
| [`cadrage.md`](cadrage.md) | PF.1 | une décision réelle, une métrique métier et une métrique technique reliées, un critère de succès chiffré fixé d'avance, des risques avec leur parade |
| [`protocole.md`](protocole.md) | PF.4 | un découpage justifié par l'audit, un test scellé, des intervalles adaptés à des données dépendantes, des baselines nommées, un budget |

Les faits sur les données (taille, période, colonnes, défauts) ont été vérifiés sur l'archive officielle de l'UCI le 5 novembre 2026 ; il n'y a **aucun résultat** de modèle dans ces pages, puisqu'un cadrage et un protocole s'écrivent avant les expériences.
