# Métiers de l'IA et de la data : ce que le workbook t'apprend pour chacun

Objectif du workbook : une reconversion. Ce document relie les compétences travaillées aux métiers visés. Il sera enrichi à chaque partie (liens vers les exercices 💼 et 🛠️ et vers les mini-projets de portfolio).

> Les intitulés varient beaucoup d'une entreprise à l'autre : lis toujours le détail d'une offre plutôt que son titre.

## Les quatre métiers visés

| Métier | Mission principale | Livrables typiques | Outils du quotidien |
|---|---|---|---|
| **Data analyst** | répondre à des questions métier avec des données | tableaux de bord, analyses, recommandations | SQL, tableur, Python (pandas), outils de visualisation, statistiques |
| **Data scientist** | construire et évaluer des modèles prédictifs | modèles, études, expérimentations, notebooks | Python, scikit-learn, gradient boosting, statistiques, un peu de deep learning |
| **ML engineer** | mettre les modèles en production et les maintenir | pipelines d'entraînement, API de prédiction, monitoring | Python, PyTorch, tests, git, conteneurs, cloud, suivi d'expériences |
| **AI engineer** | construire des applications autour de modèles pré-entraînés (LLM, vision) | assistants, recherche augmentée (RAG), intégrations | API de modèles, Hugging Face, prompting, évaluation, fine-tuning léger |

## Construire ton portfolio

- Un **mini-projet** par partie (dossier `projets/`) et le **projet final** : chacun avec un README soigné, des résultats reproductibles et une conclusion honnête (limites comprises).
- Ta librairie **mylearn**, testée : la preuve que tu comprends ce qu'il y a sous le capot.
- Ton dépôt GitHub lui-même : commits réguliers et lisibles, organisation claire.

## Préparer les entretiens
